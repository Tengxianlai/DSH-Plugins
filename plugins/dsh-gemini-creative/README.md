# dsh-gemini-creative

按需加载的“创作与审看”技能：写剧本、对白、旁白、文案，或者拿场景图、分镜、PDF 和剧本对照时，把活交给 `gemini`（见 `dsh-gemini` 插件）。

## 为什么是技能而不是提示词

- 技能只在匹配时加载，正文不进默认 system prompt，不增加每个会话的常驻上下文，也不会给上游的提示词指纹添新句子。
- 技能由模型按 description 自行选择；描述里同时写了中文触发词（写剧本、对白、旁白、文案、分镜、场景图、素材对照、长文分析）和英文触发词，避免中文请求漏触发。
- 正文可改：`assets/gemini-creative.md` 在每次加载时读取，改完新会话即生效，不用重启（目录条目的元数据改了才需要重启）。

## 内容

技能正文覆盖：

- **写**：剧本、分镜、对白、旁白、角色小传、文案、改写/润色/续写。
- **看**：场景图、分镜图、概念图、生成素材，和剧本/分镜表对照，找场景错误、语义错误、道具或光线矛盾。
- **读**：PDF、长文、访谈、设定集、CSV/JSON 清单，做结构梳理、一致性检查、版本比较。
- **选**：同一场景多个版本，判断哪一版最贴近想要的气质。
- **怎么问**：用自然语言交代背景和目的，不要写命令清单；长文放 `source`，图片/PDF/片段路径放 `files`；只有结果格式真的重要时才指定长度或结构。
- **参数**：模型固定 argon；`reasoning` 默认 medium，密集对照用 high，快速看用 low。

## 安装

由 `plugin_manager` 的 `install_bundle` 托管安装，target 用本目录的绝对路径（相对仓根是 `plugins/dsh-gemini-creative`）。

技能目录在会话开始时注入；装好后**开新会话**才能看到 `gemini-creative`。

## 依赖

运行时依赖 `dsh-gemini` 提供的 `gemini` 工具。两个插件分开安装；只装技能不装工具时，技能会指向一个不存在的工具。

## 自检

```sh
node --check index.js
node scripts/verify.mjs
```

自测检查：provider 注册、候选元数据（名称/描述/invocation/source）、正文可加载、正文包含 `gemini`、场景图触发词与中文触发词。
