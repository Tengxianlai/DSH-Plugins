# Gemini 创作与审看

一个按需加载的技能：写剧本、对白、旁白、文案，或者拿场景图、分镜、PDF 和剧本对照时，把活交给 `gemini`（Gemini 4 Argon）。

## 触发条件

描述里同时包含中文和英文触发词：

- 写：剧本、分镜、对白、旁白、角色小传、文案
- 看：场景图、分镜图、概念图、生成素材与剧本/分镜表对照
- 读：PDF、长文、访谈、设定集、CSV/JSON 清单
- 选：同一场景多个版本的比较

不触发：代码、工具调用、短事实问答、用户明确要主模型本人写。

## 技能正文说了什么

1. 用自然语言交代背景和目的：我们在做什么、材料在哪、要它看什么、什么算问题。
2. 长文放 `source`；图片、PDF、片段、文本文件路径放 `files`。工具会自动给每个附件加“文件 N：路径”标签。
3. 不要写成命令清单，也不要预设写作模式；只有结果格式真的重要时才指定长度或结构。
4. 模型固定 `gemini-4-argon`；`reasoning` 默认 medium，密集对照或深度分析用 high，快速看用 low。
5. 拿到结果后直接当合作者意见来读；“不确定”就是不确定，不要转成事实。

## 与 gemini 的关系

技能只负责“什么时候调、怎么问”；真正发请求、拼干净 system prompt、加载图片/附件、过滤思考内容的是 `dsh-gemini` 的 `gemini` 工具。两个插件分开安装，技能正文在加载时读取，改 `assets/gemini-creative.md` 不需要重启。

## 限制

- 技能是否被选中由模型按 description 判断，不是硬编码路由；要 100% 确定时，直接在请求里说“用 gemini 看”。
- 技能目录在会话开始时注入，装好或改元数据后需要开新会话。
- 工具侧附件合计上限 12MB，支持图片/PDF/片段/文本；docx/xlsx 需要先抽文本或转 PDF。
