## R1（最高）修 `minimax-video` skill：把「2K 直出」与「再生成的源条件」分开

- **证据**：`03_FAILURE_PATTERNS.md` F5；`plugins/dsh-minimax-video/skill/SKILL.md:118`（错的那句）；用户实测 Lite 768P（`9e5b4806` seq3011「实际是可以的，我测试过」）+ 项目 task `463851531801158`；纠错会话 `2f08495b`；勘误 `docs/video/H3_LITE_PILOT_20261115/LITE_REGEN_ERRATUM.md`。
- **动作**：**保留** `:23`/`:50-53` 的直出限制（那是真的）；只改 `:118`，写成「源受**物理规格**约束，`model:MiniMax-H3` 是输出模型」；并在 `README.md` 表格行注明「Lite 768P 已实测可再生成 2K；Highspeed/Max 按同一物理规格推导、未实测」。
- **效果**：消除「用户说能、模型说不能」的对抗；这是每个会话都会加载的文档，一处改动复用到所有后续项目。
- **成本**：1–2 行文本（只改 `:118`；`:23` 最多加一句交叉引用）。

## R2（最高）让空字符串参数不再是错误

- **证据**：`03_FAILURE_PATTERNS.md` F6（`213b3228` seq290–330 九连败；`9e5b4806` seq2821 已定位根因）；`plugins/dsh-minimax-video/index.js:156-157`、`lib/media.js:53-56`。
- **动作**：空/空白字符串按「未提供」处理（`reference_*` 数组过滤空项）；错误信息带上字段名。
- **效果**：本项目中可完全自动化消除的重复失败（9 次失败 + 1 次护栏中断），且不影响任何生成语义。
- **成本**：约 10 行 + 一条自测。

## R3 下载落盘可追溯：回显绝对路径 + 文件名带 task id

- **证据**：`03_FAILURE_PATTERNS.md` F12（`213b3228` seq835 与 seq862 两份互斥汇报）；`index.js:113-115`（秒级 `timestamp()`）、`:170-175`、`:409`。
- **动作**：stem 加 `task_id` 与毫秒；返回体回显最终绝对路径；描述里写明 `out_dir` 语义。
- **效果**：并行下单时不再出现「文件被覆盖/不知落在哪」，sha256 台账可对得上号。

## R5 项目规则写入「H3 下单前五条」

- **证据**：`03_FAILURE_PATTERNS.md` F1/F2/F3/F6；TanLu 仓 `AGENTS.md/STATE.md/README.md` 目前检索「空字符串/可选字段」无命中。

## R6 交付语与 JSON 强制三档状态

- **证据**：`03_FAILURE_PATTERNS.md` F9（「v02 全部可以替换 v01 当正式声线锚」vs `not_proven: 未做人耳终审`，`213b3228` seq132）。
- **动作**：`候选（未验）/ 技术通过 / 已采用（用户验收）` 三档；JSON 用 `adopted_by_user` 显式记录；禁止「可替换/可当锚」等模糊词。
- **效果**：避免把中间稿当交付物，也避免用户看到未验收内容被当成结论。

## R7 批准资产索引（关键帧 / 人物卡 / 场景母版）机器可读

- **证据**：`03_FAILURE_PATTERNS.md` F10（94 slot 里同源复用仅 1；90 格人工选片；F1 里绕过批准关键帧）；项目后期才补 `SCENE_PLATE_METHOD.md` 与 `check_scene_refs.py`。
- **动作**：一张表（path + sha256 + 覆盖镜头 + 批准状态），任何生图/生视频提交前先查；未命中才允许新生成并写明理由。
- **效果**：直接回应「人物卡场景卡复用率低」，也让「为什么又生成了一张新脸」可审计。

## R8 压缩摘要的不变量自检

- **证据**：`02_MODEL_PHASES.md` §4（换模型前的摘要里 `<d>`/台词/音色/关键帧出现 0 次，2 分钟后换模型，随后连犯四类错）。
- **动作**：摘要模板固定包含 8–10 条不变量；生成后做关键词自检（缺 `<d>`、`reference_audio` 语义、批准关键帧路径、预算余额 就报警）；换主模型时**重发**一次清单。
- **效果**：把「中途换模型就像换了个人」变成可测的上下文完整性问题。

## 一句话总结

本项目最贵的不是模型能力，而是**不变量在会话之间、以及压缩/换模型时丢失**：空字段（丢一条参数规则）、参考音频当台词（丢一条语义）、截帧顶替关键帧（丢一份资产索引）、未审即升 2K（丢一条验收顺序）。R1/R2/R3 是插件层能立刻止血的三处，R5/R7/R8 是项目层防止复发的三处。
